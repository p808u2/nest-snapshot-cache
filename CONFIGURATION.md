# Configuration guide

Start with the generic template:

```sh
cp config.example.json config.json
```

Then edit `config.json`. It is intentionally ignored by Git because it
contains the local Scrypted stream URLs.

## Finding the Scrypted stream URL

The `source` value is not the Google or Nest camera URL. It is the local RTSP
rebroadcast URL provided by Scrypted. The path usually looks like an opaque,
generated identifier, for example:

```text
rtsp://127.0.0.1:11000/7f3c9a2e5d184b6aa91e0c4f
```

That identifier is generated by Scrypted, not chosen by the user. It is used to
map the local RTSP request back to the correct camera and may change if the
rebroadcast device is recreated, reset, or reconfigured. It is not the Nest
device ID, serial number, or friendly camera name.

To find the URL:

1. Open the camera in the Scrypted Management Console.
2. Open the camera's **Rebroadcast** or **RTSP rebroadcast** settings.
3. Enable the local RTSP rebroadcast if it is not already enabled.
4. Copy the RTSP URL shown by Scrypted into the corresponding `source` field.
5. Keep the URL local; do not publish it in screenshots or public configuration.

The fictional example uses deliberately invalid values with the same general
shape as a real Scrypted path:

```json
"source": "rtsp://127.0.0.1:11000/7f3c9a2e5d184b6aa91e0c4f"
```

Those values are only there to show the shape of a completed configuration;
they will not connect to a real camera.

Treat a real RTSP URL as private. Anyone who can reach the endpoint may be able
to request the stream, so do not publish it in screenshots, examples, or issue
reports.

## Camera names

The keys under `cameras` become the snapshot path names:

- `front` → `http://127.0.0.1:18765/front.jpg`
- `back` → `http://127.0.0.1:18765/back.jpg`

Use lowercase letters, numbers, and hyphens for additional camera names.

## Crop and output settings

`output_width` and `output_height` should normally remain `1280` and `720` for
HomeKit's 16:9 layout. `crop_vertical_bias` controls the vertical position of
the crop:

- `0.00` = top
- `0.50` = centered
- `1.00` = bottom

The crop examples in the README are intended to help choose this value for a
camera with a tall or unusual native aspect ratio.

## Local paths and platform differences

The example uses the Homebrew FFmpeg path on Apple silicon macOS. On another
platform, change `ffmpeg` to the path returned by `command -v ffmpeg` and adapt
the timestamp renderer and service startup method as needed. Relative
`cache_dir` paths are resolved from the service directory.

Do not copy the live `config.json` into a public repository. It may contain
private hostnames, ports, or stream identifiers.
